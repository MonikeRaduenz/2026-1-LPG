# 2026_LP-5
### Repositório da atividade de Estruturas de Repetição (for) da matéria de Linguagem de Programação<br>

1. (De Oliveira; Manzano, 2004) Faça um programa que apresente como resultado os
quadrados dos números inteiros existentes na faixa de valores de 15 a 200.<br>

2. Faça um programa que peça ao usuário 10 números e mostre posteriormente quantos
são pares, bem como quantos são ímpares.<br>

3. (De Oliveira; Manzano, 2004) Faça um programa que apresente a soma dos cem
primeiros números naturais (1 + 2 + 3 + ... + 98 + 99 + 100).<br>

4. Faça um programa que peça ao usuário um número inteiro e um incremento inteiro.
Após, mostre na tela do 0 at´e este número, respeitando o incremento informado.<br>
• Ex.: Número = 20<br>
• Incremento = 5<br>
• Saída do programa = 0, 5 ,10, 15 ,20.<br>

5. Faça um programa que solicite ao usuário 10 números inteiros e ao final, mostre o
maior número informado. Considere que o usuário não irá informar números iguais.<br>
