# 2026_LP-3
Repositório da atividade de Estrutura de Seleção Múltipla

### Lista 03 - Estrutura de Seleção Múltipla <br>

• Entrega Esperada: 02 arquivos .c.<br>
– Atividade Individual.<br>
– Atenção! Os arquivos devem ser nomeados com a numeração equivalente a questão seguido do primeiro nome, (Ex.: 1 fulano.c, 2 fulano.c ...).<br>
– Arquivos em outro formatos não serão considerados.<br>
– Códigos criados integralmente usando recursos de IA não serão considerados.<br>
– Entregas atrasadas não serão consideradas.<br>
• Não utilize estrutura if-else neste exercício!<br>

1. Faça um programa que mostre um menu que lista todos os estados brasileiros. Cada um deve ser representado por um número. Em seguida, mostre na tela qual região o estado se localiza (Norte, Nordeste, Centro-Oeste, Sudeste ou Sul).<br>
2. Faça um programa que apresente opções para o usuário assistir em um streaming. O programa deverá ter como dados de entrada a categoria e, em seguida, perguntar a subcategoria, mostrando então a sugestão. Utilize uma estrutura switch-case aninhada.<br>
