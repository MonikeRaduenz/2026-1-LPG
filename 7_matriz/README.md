# Matrizes

1. Faça um programa que peça os valores de uma matriz 2x3 e ao final, mostre na tela o total da soma de todos os elementos dessa matriz.<p>
2. Faça um programa que peça os valores inteiros para uma matriz 3x3 e peça ao
usuário qual o número da linha que ele deseja ver os valores e mostre na tela
somente os valores dessa linha.<p>
3. Em uma matriz 4x4 preenchida com valores inteiros, mostre na tela:<br>
• A soma de todos os elementos das linhas pares;<br>
• O valor do primeiro elemento da matriz e do último;<br>
• A soma dos elementos da linha 2;<br>
• Mostre somente os elementos da Diagonal Principal;<br>
• O maior valor e sua posição na matriz;<br>
• O menor valor e sua posição na matriz.
