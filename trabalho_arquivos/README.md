Implemente um programa que leia um arquivo de texto .txt e realize as seguintes
operações:
1. Declarar uma struct para armazenar as informações de um produto: nome, quantidade e preço.
2. Solicitar ao usuário que informe o nome, a quantidade e o preço do produto e
armazenar na struct.
3. Armazenar esses dados no arquivo de texto lido utilizando a função fprintf()
(saída formatada).
